# Product Core Idea: Classroom YouTube Wrapper

**Purpose:** Transform passive YouTube course watching into an active, high-retention classroom experience.  
**Core Philosophy:** Not just another wrapper; an intentional study environment that ensures learned material is deeply embedded.

---

## 1. Target Audience & Personas

1. **Self-Taught Skill Learners (Primary):** Coders, designers, video editors, and data analysts learning practical skills from long-form YouTube courses.
2. **Exam & Certification Preparers:** Students studying for school boards, entrance exams, or technical certifications using YouTube playlists.
3. **Upskilling Professionals:** Working adults studying in constrained evening/weekend time slots needing high efficiency.
4. **School-Age Students:** Learners seeking structured homework assistance and subject mastery.

---

## 2. Core Problems & Functional Solutions

| Problem | Feature / Solution |
| :--- | :--- |
| **Scattered course tracking** | Central dashboard managing all enrolled YouTube playlists, progress tracking, and deadline countdowns. |
| **Passive watching & low retention** | Mandatory active recall: short quizzes after each chapter/topic; return-session recall cards. |
| **Fragmented note-taking** | In-player notes pad beside video with clickable `[MM:SS]` timestamps; compiled into a single exportable course document. |
| **Procrastination & overwhelm** | Structured study blocks ("class times"), calendar notifications, deadline-driven priority sorting, and completion-pace predictors. |
| **Mental fatigue & cognitive overload** | Scientific focus pacing (20m study / 5m break) with physical step-aside reminders; 2-hour single-subject burnout alerts. |
| **Lack of reading materials** | One-time AI-generated course and chapter summary notes for rapid revision without rewatching videos. |
| **Post-course knowledge decay** | Spaced recall protocols (flashcards, blurting, periodic review) for flagged "Important" courses. |
| **Inconsistent motivation** | Daily study streak counter (with grace/sick-day protection) and competitive study leaderboards. |

---

## 3. Experience Flow & Study Rituals

- **Pre-Session:** Optional 2-minute calming ritual (deep breathing / focus check) to prime attention.
- **In-Session:** Video player + synced notes + optional ambient/binaural focus audio toggle.
- **Pacing:** 20m focus block -> 5m diffuse break (away from screen) -> Return recall check.
- **Post-Session / Milestone:** Clean summary screen celebrating progress, streak increment, and next priority.

---

## 4. Advanced & Extended Features (Roadmap)

- **Crowd Insight:** Visual indicator of the "most noted parts" of a playlist.
- **Syllabus Mapper:** Map YouTube playlists directly against standard exam or curriculum syllabi.
- **Diagnostic Analytics:** Topic-level mastery breakdown (e.g., *"20% accuracy in Recursion"*).
- **Curated Library:** Built-in directory of vetted, high-quality YouTube courses.
- **Buddy Up:** Small-group collaborative study cohorts progressing through the same playlist.
- **Power Ergonomics:** Full keyboard navigation shortcuts.
